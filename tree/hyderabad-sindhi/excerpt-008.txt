انٽرنيٽ پتو IP Addresses جو ئي جهرمٽ آهي جنهن سان ڪمپيوٽر ۽ ٻيا ڊوائيسز هڪ ٻئي کي پوري دنيا منجهه سڃاڻيندا آهن ۽ انهن IP Addresses سان ئي گلوبل نيٽورڪ ٺهيل آهن. ٻڌائيندو هلان ته جڏهن ٻه مختلف نيٽورڪ پاڻ ۾ ملندا آهن ته ان کي گلوبل نيٽورڪ چئجي ٿو. توهان گلوبل وليج بابت ٻڌو ته هوندو، اها IP Address ئي آهي جنهن سبب دنيا گوبل وليج ٿي وئي آهي. 192.168.1.1يا ان ريت لکيل انگ توهان اڪثر ڏٺا هوندا، ان کي IP Address چئجي ٿو جيڪا نيٽورڪ جو بنيادي جزو آهي. IP Address جي حد 0.0.0.0 کان 255.255.255.255 تائين ٿئي ٿي ۽ اهائي نيٽورڪ جي سڃاڻپ آهي.
