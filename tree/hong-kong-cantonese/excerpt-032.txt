CERN 喺 1993 年將互聯網協議同埋代碼免費提供，令到佢可以廣泛使用。 喺國家超級計算應用中心喺嗰年稍後時間發佈咗 Mosaic 網頁瀏覽器 之後，互聯網嘅受歡迎程度迅速增長，因為數以千計嘅網站喺唔夠一年嘅時間入面湧現出嚟。 Mosaic 係一個圖形瀏覽器，可以顯示嵌入式圖像同埋提交表格，呢啲表格會由 HTTPd 伺服器處理。 馬克·安德森 同 占·克拉克 喺第二年創立咗 Netscape，並且發佈咗 Navigator 瀏覽器，佢將 Java 同 JavaScript 引入到互聯網。佢好快就成為咗佔主導地位嘅瀏覽器。Netscape 成為咗上市公司喺 1995 年，噉樣觸發咗對互聯網嘅狂熱，並且開始咗dot-com 泡沫。 Microsoft 通過開發自己嘅瀏覽器 Internet Explorer嚟回應，開始咗瀏覽器大戰。通過將佢同 Windows 捆綁埋一齊，佢成為咗 14 年嘅主導瀏覽器。

Berners-Lee 創立咗 World Wide Web Consortium（W3C），佢喺 1996 年創建咗 XML，並且建議用更嚴格嘅 XHTML 嚟取代 HTML。 與此同時，開發人員開始利用一個叫做 XMLHttpRequest 嘅 IE 功能嚟製作 Ajax 應用程式，並且發起了 Web 2.0 革命。Mozilla、Opera 同 Apple 拒絕咗 XHTML，並且創建咗 WHATWG，佢哋開發咗 HTML5。 喺 2009 年，W3C 讓步並且放棄咗 XHTML。 喺 2019 年，佢將 HTML 規範嘅控制權移交畀咗 WHATWG。

World Wide Web 對於資訊時代嘅發展至關重要，並且係數十億人喺互聯網上面互動嘅主要工具。

添·柏納斯-李 指出，「World Wide Web」嘅正式拼寫係三個獨立嘅詞，每個詞都大寫，中間冇連字符。 儘管如此，佢通常都係簡稱為「the Web」，亦都經常叫做「the web」；詳情請參閱 「Internet」嘅大寫。喺普通話入面，「World Wide Web」通常通過語音語義匹配翻譯成「wàn wéi wǎng」（万维网），噉樣滿足咗「www」嘅要求，字面意思係「萬維網」，呢個翻譯反映咗 World Wide Web 嘅設計概念同埋普及程度。

喺英文入面，「www」通常讀做「double-u double-u double-u」。 一啲用戶將佢發音為「dub-dub-dub」，尤其係喺新西蘭。 史蒂芬·弗萊 喺佢嘅「Podgrams」系列播客入面，將佢發音為「wuh wuh wuh」。 英國作家 道格拉斯·亞當斯 曾經喺《獨立報星期日版》（1999 年）入面詼諧噉講：「World Wide Web 係我唯一知道嘅嘢，佢嘅縮寫形式用嘅時間比佢縮寫嘅嘢長三倍。」

「互聯網」同「World Wide Web」呢兩個詞語經常唔加以區分噉使用。然而，呢兩個詞語嘅意思唔係一樣嘅。「互聯網」係一個通過電信同光纖網絡互連嘅電腦網絡全球系統。相反，「World Wide Web」係一個全球性嘅文件同其他資源集合，通過超連結同URI連結埋一齊。網絡資源係使用HTTP或者HTTPS嚟存取嘅，呢啲係應用程式級別嘅互聯網協議，佢哋使用互聯網傳輸協議。

喺 World Wide Web 上面瀏覽網頁通常係從喺網頁瀏覽器入面輸入網頁嘅URL，或者跟住一個超連結到嗰個網頁或者資源開始嘅。然後，網頁瀏覽器會啟動一系列嘅後台通信消息，去獲取同埋顯示請求嘅網頁。喺 1990 年代，使用瀏覽器嚟瀏覽網頁 - 以及通過超連結從一個網頁移動到另一個網頁 - 開始被稱為「瀏覽」、「上網」（模仿頻道衝浪）或者「導航互聯網」。早期對呢種新行為嘅研究調查咗用戶喺使用網頁瀏覽器時嘅模式。例如，一項研究發現咗五種用戶模式：探索性瀏覽、視窗瀏覽、進化瀏覽、有界導航同埋目標導航。

與格──用於名詞作為句子嘅間接受詞，或者配合特定動詞、某啲介詞，甚至用作表示行為者、參照或擁有者。例如，商人將stola遞畀嗰個女人（Mercātor fēminae stolam trādit.）。

賓格──用於名詞作為主語嘅直接受詞，或者作為表示去向嘅介詞受詞，有時亦用嚟表達一段時間嘅持續。例如，個男人殺咗個細路仔（Vir puerum necāvit.）。

奪格──用於表示名詞表達分離、來源、原因、行為者或工具作用，又或者當名詞用作某啲介詞嘅受詞，同時亦用嚟指明特定嘅時間或地點（副詞性用法）：你同個細路仔一齊行咗（Cum puerō ambulāvistī.）。

呼格──用於直接稱呼時。名詞嘅呼格形式通常同主格一致，但對於第二變格以-us結尾嘅名詞除外，嗰個-us喺呼格單數變成-e。如果結尾係-ius（例如fīlius），則結尾變成-ī（filī），同主格複數（filiī）有所區別。例如，奴隸大叫：「Domine！」（"Domine!" clāmāvit servus.）。

所在格──用於指示位置（相當於英文嘅「in」或「at」）。呢個格比起其他六個格嚟講用得少，通常適用於城市、小鎮、島嶼，或少數常見嘅名詞，例如domus（屋企）、humus（土地）同rus（鄉下）。喺第一同第二變格嘅單數中，所在格形式同所有格一致（例如Roma變做Romae，意即「喺羅馬」）；而喺所有變格嘅複數及其他變格嘅單數中，所在格形式同奪格一致（例如Athēnae變做Athēnīs，意即「喺雅典」）。喺第四變格嘅名詞domus中，所在格形式為domī（意即「喺屋企」），與其他格嘅常規形式有所唔同。

拉丁文冇定冠詞同不定冠詞，所以puer currit可以解作「個細路仔喺跑」或者「有個細路仔喺跑」。

拉丁文規律形容詞主要分為兩種類型：第一同第二變格型，以及第三變格型。咁叫係因為佢哋嘅變化形式分別同第一、第二變格名詞或第三變格名詞相似或一致。拉丁形容詞仲有比較級同最高級形式，同時亦有唔少拉丁分詞。拉丁數詞有時亦會作形容詞變格；詳情請參閱§ 數字。

第一同第二變格型形容詞：陰性形式嘅變化同第一變格名詞一致，而陽性同中性形式則同第二變格名詞一致。例如，形容詞 mortuus, mortua, mortuum（意即「死咗嘅」）：其中 mortua 嘅變化就似一般第一變格名詞（例如 puella「女仔」），mortuus 嘅變化則似一般第二變格陽性名詞（例如 dominus「主人」），而 mortuum 嘅變化就似一般第二變格中性名詞（例如 auxilium「幫助」）。
